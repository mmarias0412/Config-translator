# config-translator

Инструмент командной строки для учебного конфигурационного языка
(вариант 22, дисциплина «Конфигурационное управление»). Читает текст
на учебном языке из файла и печатает эквивалентный JSON в стандартный
вывод. Синтаксические и семантические ошибки выявляются с сообщением
о строке и столбце (сообщения на русском языке).

Синтаксический разбор выполнен с помощью библиотеки
[pyparsing](https://github.com/pyparsing/pyparsing).

## Язык

| Конструкция | Синтаксис | Пример |
|---|---|---|
| Число | `\d*\.\d+` | `.5`, `3.14`, `10000.0` |
| Массив | `'( значение значение ... )` | `'( .1 .2 .3 )` |
| Словарь | `[ имя => значение, ... ]` | `[ a => .5, b => '( .1 ) ]` |
| Имя | `[a-z][a-z0-9_]*` | `day_target` |
| Объявление константы | `let имя = значение` | `let pi = 3.14` |
| Вычисление константы | `.{имя}.` | `.{pi}.` |

Правила:

- значение: число, массив, словарь или вычисление константы;
- конфигурация состоит из объявлений констант и одного корневого
  значения, которое идёт после всех объявлений и попадает в JSON;
- константы вычисляются на этапе трансляции в порядке объявления:
  константа может ссылаться только на ранее объявленные;
- результатом `.{имя}.` является значение константы (число, массив
  или словарь), его можно использовать в любом месте, где допустимо
  значение, в том числе внутри вложенных конструкций;
- элементы массива разделяются пробелами, пары словаря запятыми;
  после последней пары словаря запятая необязательна;
- массив и словарь могут быть пустыми: `'( )`, `[ ]`;
- пробелы и переводы строк между лексемами игнорируются, внутри
  `.{имя}.` пробелы недопустимы, соседние числа разделяются пробелом.

## Описание функций

| Модуль | Назначение |
|---|---|
| `src/grammar.py` | грамматика на pyparsing, `parse_text(text)` строит синтаксическое дерево |
| `src/nodes.py` | типы узлов дерева (`Number`, `Array`, `Dictionary`, `Ref` и др.) |
| `src/evaluator.py` | `evaluate_program(program)` вычисляет константы и превращает дерево в значения |
| `src/translator.py` | `translate(text)` объединяет разбор, вычисление и вывод JSON |
| `src/cli.py` | `run(argv)` разбор аргументов, чтение файла, вывод, коды возврата |
| `src/main.py` | точка входа `python -m src.main` |
| `src/errors.py` | `ConfigSyntaxError`, `ConfigNameError` |

### Настройки

| Ключ | Описание |
|---|---|
| `-i FILE`, `--input FILE` | путь к входному файлу (обязательный, UTF-8, BOM допускается) |
| `-h`, `--help` | справка |

Код возврата: `0` успех, `1` ошибка чтения файла, синтаксиса или имён
(сообщение в стандартный поток ошибок, JSON не печатается).

Виды ошибок:

- синтаксическая ошибка: `ошибка: строка 2, столбец 8: ожидалось: ']'`;
- константа не определена или объявлена повторно;
- повторяющийся ключ словаря.

## Сборка и тесты

Нужен Python 3.9+.

```
pip install -r requirements.txt
python -m unittest discover tests
```

Сборка не требуется. Тесты покрывают все конструкции языка, их
вложенность, ошибки и оба примера из `examples/`.

## Запуск

```
python -m src.main --input examples/smart_home.conf
./run.sh --input examples/smart_home.conf       (Linux, macOS)
run.bat --input examples\smart_home.conf        (Windows)
```

## Примеры

### Умный дом (`examples/smart_home.conf`)

```
let comfort = 21.5
let night = 18.0
let hysteresis = .5

[
  thermostat => [
    day_target => .{comfort}.,
    night_target => .{night}.,
    hysteresis => .{hysteresis}.,
    schedule => '( 6.30 .{night}. 22.0 .{comfort}. )
  ],
  lamp => [
    brightness => .8,
    warm_levels => '( .2 .5 .8 )
  ]
]
```

Результат:

```json
{
  "thermostat": {
    "day_target": 21.5,
    "night_target": 18.0,
    "hysteresis": 0.5,
    "schedule": [6.3, 18.0, 22.0, 21.5]
  },
  "lamp": {"brightness": 0.8, "warm_levels": [0.2, 0.5, 0.8]}
}
```

(в реальном выводе массивы печатаются по одному элементу в строке).

### Банковские тарифы (`examples/bank_tariffs.conf`)

```
let base_rate = .075
let fee = 1.5
let tiers = '( 10000.0 50000.0 100000.0 )

[
  deposit => [
    rate => .{base_rate}.,
    bonus_rate => .01,
    tiers => .{tiers}.
  ],
  card => [
    monthly_fee => .{fee}.,
    cashback => '( .01 .02 .05 ),
    limits => [ daily => 5000.0, monthly => .{tiers}. ]
  ]
]
```

Результат (`python -m src.main -i examples/bank_tariffs.conf`):

```json
{
  "deposit": {
    "rate": 0.075,
    "bonus_rate": 0.01,
    "tiers": [10000.0, 50000.0, 100000.0]
  },
  "card": {
    "monthly_fee": 1.5,
    "cashback": [0.01, 0.02, 0.05],
    "limits": {"daily": 5000.0, "monthly": [10000.0, 50000.0, 100000.0]}
  }
}
```

### Пример ошибки

```
$ echo "[ a => .{zz}. ]" > bad.conf
$ python -m src.main -i bad.conf
ошибка: строка 1, столбец 8: константа 'zz' не определена
```
